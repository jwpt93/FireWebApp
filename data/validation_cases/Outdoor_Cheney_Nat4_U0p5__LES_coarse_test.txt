#               Question: does coarse Smagorinsky (sub-grid nu_t ~ k-ε scale)

#               lit-pattern test demonstrated fixes plume reversal.
#
# Calibration vs validation:
#   This is a SCOUT (no acceptance band — qualitative go/no-go for whether

#   Mesh + LES + SEM:           Mell 2007, Moinuddin 2018, Innocent 2023.
