# ── Cross-language integration case: JS port vs Python reference ──────────
#
# NOT a validation case. There is no experiment behind these numbers and no
# acceptance band on the physics. Its only job is to be a case BOTH codes can
# run to completion in reasonable wall time, so their ROS can be compared.
#
# Deliberately small: Ny = 1 (the FFT preconditioner in the port is ported for
# the single-cell periodic direction only), a 3 m domain, a coarse 0.10 m dx,
# 4 particles per cell, and 0.6 s of simulated time. The production Cheney
# deck is 384,000 cells; this is 720.
#
# Every physics option matches the production Cheney Cut-4 configuration —
# Lagrangian bed, k-epsilon, EDC, DOM, FFT-PCG, combined drying, geometric
# view factor. What differs is only resolution and duration.
#
# Because the mesh is coarse and the run short, the ROS this produces is NOT
# a physically meaningful spread rate and must not be quoted as one. Two codes
# solving the same discrete equations on the same coarse mesh should still
# agree with each other, and that agreement is the whole point.
